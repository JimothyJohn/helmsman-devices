# Schneider Electric Modicon TM3 bus coupler TM3BCEIP

IP20 bus coupler that puts Modicon TM3 expansion modules on Ethernet: Ethernet/IP adapter and Modbus TCP/IP server, two isolated switched RJ45 ports, 10/100 Mbit/s, with RSTP, SNMP, a web server and a USB mini-B configuration port (data sheet, p. 1). The data sheet states the supply for the internal bus at 0.8 A for at most 7 expansion modules.

There is no EDS to read, so the folder has no identity or assembly sizes, and the point map depends on the TM3 modules fitted behind the coupler, so there are no points. What a unit reports is the open question in `device.toml`.

The documents are listed in `collect/` with their hashes; they are not in this repository.
