# Schneider Electric PowerLogic PM5560

Panel-mount power and energy meter (96 x 96 mm, display, METSEPM5560) with dual switched Ethernet ports. It speaks Modbus TCP, BACnet/IP, EtherNet/IP (ODVA-certified) and DNP3 together, and works as a Modbus Ethernet gateway to serial devices on TCP port 502 (User Manual pp. 17-18 and 126).

The user manual does not list registers: it points to the meter's Modbus register list on se.com, a spreadsheet that sits behind a FAQ page and is not collected here. So the folder has no points. Read the register list for the firmware the meter reports before adding any.

The documents are listed in `collect/` with their hashes; they are not in this repository.
