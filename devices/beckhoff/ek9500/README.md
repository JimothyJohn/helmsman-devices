# Beckhoff EK9500

Bus coupler for EtherCAT terminals: an EtherNet/IP adapter with no I/O of its own.

Identity (vendor 106, device type 12, product code 9500) and assembly instances 129 in / 130 out / 128 config are from the manual's Identity and Assembly objects (p. 61) and its Studio 5000 setup (p. 57). Sizes follow the EtherCAT terminals attached, so the folder gives none. There is no vendor EDS: the coupler's web pages write one, generic or for the terminal set it has (p. 42).
