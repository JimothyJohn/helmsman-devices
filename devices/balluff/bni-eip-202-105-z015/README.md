# Balluff BNI EIP-202-105-Z015

Order code BNI005J (manual PDF p. 38, section 10.3). Process data: input assembly
instance 100, 6 bytes; output assembly instance 101, 6 bytes
(manual PDF p. 23). Vendor id and product code are not given in the
manual; they are left out until an EDS or a unit says.

Source: `collect/balluff.toml`, the Bedienungsanleitung. Vendor files are not in
this repository; fetch them with `scripts/docs-fetch.py` and check the hash.
