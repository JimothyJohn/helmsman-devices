# Brainboxes ED-538

Ethernet to 8 DI and 4 DO. **Not usable out of the box**: ED units ship with the ASCII protocol and Modbus TCP is switched on in the web console (Modbus TCP Manual p. 3), so a box that adds devices without preconfiguration cannot use one until that is done, or until helmsman sets it. Map from §9.3.

The manuals are listed in `collect/` with their hashes; they are not in this repository.
