# Acromag XT1111-000

BusWorks XT 16-channel sinking discrete I/O: 16 active-low inputs with 16 low-side switch outputs (cover). Modbus TCP/IP over 10/100 Ethernet, configured only over USB: there are no Modbus registers for configuration (manual p. 32-33). Functions: 03, 04, 06, 16 and a hidden 17 Report Slave ID (p. 32); no coil functions, so I/O is by 16-bit words, four channels to a word, which the manual's register map (pp. 33-36) lists.

The manual is listed in `collect/` with its hash; it is not in this repository.
