# Advantech ADAM-6015

7-channel isolated RTD input module (PT100, PT1000, Balco 500, Ni), 16-bit, 10/100BASE-T, Modbus/TCP (section 4.2, p. 18). Map from Appendix B.2 (pp. 191-195). The manual notes that some addresses are supported only by the DE version; the marking is a colour the text layer does not carry.

The manuals are listed in `collect/` with their hashes; they are not in this repository.
